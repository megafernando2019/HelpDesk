Pasos a seguir para deploy de la aplicación HelpDesk

A CONSIDERAR LAS VERSIONES DE LAS TEGNOLOGIAS:

- php 8.2
- Laravel 12
- Mysql  (Version 8.0.30) Esto puede varia segun laque se tenga instalada en local o hosting.


Llenado de datos para la base de datos

1.Configure y nombre a su base datos con el nombre que va a usar para la ejecución del archivo sql
EJEMPLO:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=helpdesk_nuevo
DB_USERNAME=root
DB_PASSWORD=

2.Ejecute el archivo sql que contiene la radiografia de todas las tablas que va a ocupar el sistema

php artisan migrate


3.Cargue el archivo dump inicial para probar las tablas de información.
Considere que la informacion del archivo dump (helpdesk-inicial-dump-helpdesk_nuevo-202610301549.sql) contiene solo los datos estaticos básicos para comenzar
